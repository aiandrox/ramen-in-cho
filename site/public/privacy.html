プライバシーポリシー

制定日: 2026年10月3日

END（@aiandrox）（以下「運営者」）は、スマートフォンアプリ「麺印帳（Ramen-In-Cho）」（以下「本アプリ」）およびそのWebサイト（以下あわせて「本サービス」）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 記録・写真は端末の中にだけ保存します

本アプリで記録したラーメンの記録（店・日時・系統・評価・「この一杯について」・待ち時間など）、写真、店ごとの覚え書き、願掛け（行きたい店）、アプリの設定は、利用者の端末の中にだけ保存します。運営者のサーバーや外部のサーバーに送ったり、保存したりすることはありません。本アプリにはログインやアカウントはありません。

これらのデータは本アプリを削除すると消去されます。バックアップ機能を使うと、記録と写真を1つの zip ファイルにまとめ、端末の共有画面から利用者が選んだ保存先（「ファイル」アプリ、クラウドストレージ、メールなど）に書き出します。書き出したファイルは、利用者が選んだ保存先のサービスの規約に従って取り扱われ、運営者が受け取ることはありません。共有カードなど、利用者が自ら共有画面で送る画像も同様です。

2. 位置情報について

本アプリは、アプリを使っている間だけ端末の位置情報を使います。アプリを閉じている間の位置情報（バックグラウンドの位置情報）は使いません。位置情報は次の目的で使います。

  • 現在地の近くのラーメン店を探して、記録の候補に出すため
  • 「並んだ」を記録するときに、店から100m以内にいることを確かめるため
  • アプリを開いたときに、記録したことのある店や願を掛けた店の近くにいれば「並んだ？」とお知らせするため（この判定は端末の中だけで行い、サーバーには問い合わせません）
  • 地図に現在地を表示するため

位置情報の利用を許可しなくても、店名を手で入力して記録できます。位置情報の履歴を運営者が利用者ごとに保存することはありません。

3. 外部に送信する情報と送信先

本アプリは、次の場合に限って外部と通信します。いずれも、利用者を識別するID（広告IDなど）や、記録・写真を送ることはありません。

  • 店の検索: 近くの店を探すときは検索の中心の座標と半径を、店名で探すときは入力した店名を、運営者の検索サーバー（Cloudflare 上で動く ramen-in-cho.aiandrox.com）に送ります。検索サーバーは、利用者に代わって OpenStreetMap の Overpass API、OpenPOI API、Yahoo! JAPAN の YOLP（ローカルサーチ）に問い合わせ、結果をまとめて返します。検索サーバーに接続できないときなどには、本アプリが Overpass API と OpenPOI API に直接同じ内容を問い合わせることがあります（Yahoo! JAPAN には検索サーバーだけが問い合わせます）。
    利用目的: 近くのラーメン店や、入力した名前の店を候補として表示するため。
  • 店の一覧の取得: 運営者が手で管理している店の一覧（ラーメン二郎の直系店など）を、1日に1回程度、運営者のサーバーから受け取ります。この通信で利用者の位置や記録を送ることはありません。
    利用目的: アプリを更新しなくても、店の情報を最新に保つため。
  • 地図の画像: 地図を表示するときは、OpenStreetMap の地図画像サーバー（tile.openstreetmap.org）から画像を取得します。このとき、表示している地図の範囲が送られます。
    利用目的: 地図を表示するため。

これらの通信では、通信の仕組み上、利用者の端末のIPアドレスと通信日時が送信先に伝わります。各サービスでの取り扱いは、それぞれの運営者のプライバシーポリシーによります。

4. 検索サーバーで保存する情報

  • 検索サーバーは、同じ場所の検索に速く応えるため、検索の結果（店の名前と位置など）を、おおよその区画（約300m四方）ごとに1週間程度保存します。この保存は区画ごとで、利用者ごとではなく、誰が検索したかは記録しません。
  • 検索サーバーの基盤である Cloudflare, Inc. の標準の仕組みにより、IPアドレス、アクセスの日時、リクエストの内容などを含む通信記録が一時的に記録されることがあります。運営者は、これを障害の調査と不正な利用の防止のためにだけ使います。
  • 1台の端末からの問い合わせが多すぎないよう、IPアドレスから作った元に戻せない値（ハッシュ値）ごとに問い合わせの回数だけを数え、最長1日で消します。IPアドレスそのものや検索の内容は、この数えるための記録には含めません。

5. 端末の中だけで扱う情報

  • 写真の撮影日時・撮影場所: ギャラリーから写真を選んだときは、写真に記録された撮影日時と撮影場所（Exif）を端末の中で読み取り、食べた日時や店の候補を探すために使います。撮影場所を使って店を探す場合は、第3項のとおり検索の中心の座標として送ります。写真そのものは送りません。
  • 通知: 並んでいる間の経過時間や、週ごとの連続記録のお知らせは、端末の中で予約・表示する通知です。通知のためのサーバーや、通知用のIDの送信はありません。

6. 利用しないもの

本アプリは、利用状況の計測（アクセス解析）、エラー情報の自動送信、広告、トラッキングのためのツール（SDK）を組み込んでいません。広告IDも取得しません。

7. 第三者提供

運営者は、次の場合を除き、利用者の個人情報を本人の同意なく第三者に提供しません。

  • 法令に基づく場合
  • 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが困難な場合
  • 国の機関などが法令の定める事務を行うことに協力する必要がある場合
  • 利用目的の達成に必要な範囲で、情報の取り扱いを外部に委託する場合（第3項・第4項の外部サービスの利用を含みます）

8. 外国にある事業者への送信

第3項・第4項の情報の一部は、次の外国にある事業者に送信され、その国で処理されることがあります。

  • Cloudflare, Inc.（アメリカ合衆国）: 検索サーバーと店の一覧の配信の基盤です。Cloudflare は世界各地のデータセンターで通信を処理するため、処理される国をあらかじめすべて特定することはできません。アメリカ合衆国には日本の個人情報保護法に相当する連邦レベルの包括的な法律はなく、州ごとに個人情報の保護に関する法律が定められています。Cloudflare は、データ処理に関する規約に基づき、ISO/IEC 27001 などの認証の取得を含む安全管理措置を講じています。
  • OpenStreetMap Foundation（英国）: Overpass API の一部の公開サーバーと、地図画像サーバーの運営者です。英国は、個人情報保護委員会により日本と同等の水準にある個人情報保護制度を有する地域として指定されています。

なお、Overpass API の公開サーバーや OpenPOI API は、運営者以外の事業者・団体が運営しており、所在国や安全管理の内容は各運営者の定めによります。各国の個人情報の保護に関する制度については、個人情報保護委員会のWebサイトもご参照ください。

9. 安全管理

運営者は、取り扱う情報の漏えい・滅失・毀損を防ぐため、通信の暗号化、サーバーのアクセス権限の管理など、必要かつ適切な安全管理措置を講じます。

なお、運営者は記録や写真を保有しておらず、検索サーバーの情報も利用者ごとに保存していないため、ご請求の内容によっては、ご本人の情報を特定できず対応できない場合があります。端末の中の記録と写真は、本アプリを削除することで、利用者ご自身で消去できます。
