# 道中記の言い回し

1杯ごとの道中記に出てくる文の一覧。管理用。

- 定義は `lib/features/journal/journal_phrases.dart`
- 上から順に、当てはまる文を1つずつつないで道中記にする。候補が複数あるときは、記録ごとに1つに決まる（開くたびには変わらない）
- `{ }` の中は、その1杯の数字や名前に置き換わる
- 候補の並びを変えたり候補を足したりすると、過去の道中記の文も変わる
- 言い回しを足したり変えたりしたら `flutter test --dart-define=UPDATE_JOURNAL_CATALOG=true test/tool/journal_catalog_test.dart` でこの一覧を作り直す

## 着丼

{一杯}は「限定の」＋系統名＋「の一杯」（系統なしは「ラーメンの一杯」）。共有カードで修行点を外すため「、修行点 {点}」の形は崩さない

| いつ | 言い回し |
|---|---|
| 願の店・撤退のあと・60分以上並んだ | ついに着丼。{一杯}、修行点 {点}。<br>待ち焦がれた着丼。{一杯}、修行点 {点}。<br>苦難の末に着丼。{一杯}、修行点 {点}。 |
