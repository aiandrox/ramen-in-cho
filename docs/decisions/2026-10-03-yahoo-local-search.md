# Yahoo! ローカルサーチはサーバーだけが使う

- 日付: 2026-10-03
- 決定: 業種コード 0106（ラーメン・つけ麺）で探し、主な業種がラーメンでない店は除く。同じ店は OSM → Yahoo! → OpenPOI の順に優先して1つにまとめる。Client ID はサーバーの secret（`YAHOO_APP_ID`）だけに置き、アプリのビルドには入れない。出典「Web Services by Yahoo! JAPAN」を、Yahoo! の結果を出す画面（検索結果の下・周辺の店を出した地図）と出典の画面に出す。住所から位置を求めるのもサーバー経由の Yahoo! ジオコーダ（`/api/v1/geocode`）
- 理由: 日本のラーメン店に強く業種で絞れるため。アプリに ID を入れると取り出されうるため。無償のアプリなら無料で使える
