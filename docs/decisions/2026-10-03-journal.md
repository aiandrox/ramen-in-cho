# 道中記は記録から組み立て、言い回しは定義ファイルに置く

- 日付: 2026-10-03
- 決定: 1杯ごとの物語（願・撤退・並び・着丼・節目・土地・季節など）を記録から組み立て、保存しない。ひな形は `lib/features/journal/journal_phrases.dart`、一覧は `docs/journal/`（テストで定義から作る）。言い回しは記録の ID で決め、開くたびに変わらない。土地の一文はいつもの店（いちばん通った店）からの距離で3段階（20km 未満＝街・20km 以上＝遠出・80km 以上＝遠征）。店の市区町村は店のページを開いたときに OpenPOI で1回だけ調べて保存する
- 理由: ただの記録を「自分の修行の1話」として読み返せるようにするため。通信先を増やさず、何度も問い合わせないため
