# 過去の写真は、ギャラリーで何枚も選んで続けて記録できる

- 日付: 2026-10-07
- 決定: 記録画面の「ギャラリーから選ぶ」で何枚も選べるようにする（`image_picker` の `pickMultiImage`。30枚まで。1枚だけ選んだときは今までどおり）。選んだ写真ごとに今の記録画面を1枚ずつ開き、店の探し方・食べた日時（撮影日時）・各項目は1枚のときと同じにする（ただし2枚目からは、並んでいる最中でも並んでいる店を先に選んでおかない。過去の別の店の写真を続けて記録するときに、並んでいる店で保存してしまわないため）。上に「写真 2/5」と「この写真は飛ばす」を出し、保存ボタンは最後の1枚の前まで「着丼！（次へ）」にする。写真は開いた1枚ずつ下書き用のフォルダに写し、保存するときに今までどおり documents に写す。保存直後の演出は1枚ごとには出さず、全部終えたあとに1回だけ、印を並べて杯数・合計の修行点（累計の増えた分。過去の日時の杯を足すと、ほかの杯の初訪問ボーナスが動くことがあるため）・修行点の帯・上がった段位の数・願成就・型と秘伝をまとめて出す（記録したのが1杯だけならいつもの結果の画面）。閉じたときに通知の許可を尋ね、印帳のいちばん上に戻るのも同じ。途中で閉じたときは、保存した分は残り、今の1枚だけを今までどおり下書きに残すか破棄するかを選ぶ。まだ開いていない写真は下書きに入れず、閉じる前の確かめの窓で「ギャラリーから選び直せる」と伝える。保存した分があれば、閉じたあとにその分の結果を見せる
- 理由: 過去の写真をまとめて記録したいという利用者の要望。下書きは1件の記録を残す仕組みなので、まだ開いていない写真まで下書きに持たせると、写真の一時ファイルが OS に消されたときに読めなくなるなど仕組みが複雑になる。写真はギャラリーに残っているので選び直せば足りる。段位は1杯で1つずつしか上がらないので、まとめた記録が無かった場合との差（記録の順に数え直した段位の差）で数える
