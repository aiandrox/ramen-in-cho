# 使い方の統計を Firebase Analytics で取る

- 日付: 2026-10-07
- 決定: `firebase_analytics`（BSD-3-Clause、Firebase 公式）を入れ、記録・検索・並ぶ・願・地図・共有・バックアップ・拠点・案内・権限の拒否などをイベントとして送る。値は種類（英字の決まった言葉）・幅にまとめた数（杯数・修行点・日数・かかった時間）・1/0 だけにし、店名・位置・写真・メモ・願の中身・リンク・記録の日時は送らない。イベントの定義は `lib/features/analytics/analytics_events.dart` に1箇所でまとめる。広告 ID・Android の端末 ID（SSAID）・iOS の IDFV は集めず（Android は広告 ID の権限も外す）、広告のパーソナライズにも使わせない。iOS の追跡の許可（ATT）は出さない。設定のオン・オフは作らず常に送り、送る内容はプライバシーポリシーで公表する
- 理由: どの機能が使われているかがわからないと、伸ばす・消すの判断ができないため。通信先が増えるので aiandrox が案 B（Firebase Analytics）を選び、オン・オフは face-seal に合わせて作らないことにした
