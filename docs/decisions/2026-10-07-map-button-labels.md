# 地図の丸いボタンに、何のボタンかを字で添える

- 日付: 2026-10-07
- 決定: 地図の右下の丸いボタンの左に「一覧」「現在地」「このあたりを探す」、右上の旅路の下に「旅路」を、薄い和紙の地に小さな字（12）で添える。字を押してもボタンと同じことをする。読み上げはボタンの名前（長押しの説明と同じ）で足りるので、添えた字は読み上げない。地図の出典は添えた字の幅まで避け、大きな文字の設定でも字は1.3倍までにとどめる。探している間は字も薄くする。地図が空のときの案内も「右下の「このあたりを探す」のボタンで…」と、添えた字に合わせた
- 理由: 絵だけでは、どれが探すボタンか押すまでわからなかったため（利用調査）。地図を隠しすぎないよう、字は小さく短くした
