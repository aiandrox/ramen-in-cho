# サーバー（site/）の wrangler を v4 に上げる

- 日付: 2026-10-07
- 決定: `site/` の `wrangler` を ^3.90 から ^4（4.148）に上げる。v4 が `@cloudflare/workers-types` の v5 を求めるので、こちらも ^4 から ^5 に上げる（どちらも Cloudflare 公式、MIT OR Apache-2.0）。デプロイ（site-deploy.yml）のコマンドは v4 でもそのまま使える。v4 は Node 22 以上が要るので `engines` に書いた（CI は Node 24）。workers-types v5 は最新の実行環境の型だけを持つので、`compatibility_date`（2025-01-01）より新しい API を使うときは、日付を上げてから使う
- 理由: v3 は実行のたびに古い版の警告が出て、ログの見方（`pages deployment tail`）などの案内も v4 に合わせたいため
- 関連: #286
