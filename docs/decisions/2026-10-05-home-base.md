# 拠点は利用者が地図で決める

- 日付: 2026-10-05
- 決定: 設定の「拠点」で（初めての案内では聞かない。2026-10-08-onboarding-2-steps.md）、地図の真ん中の「拠」の場所を選び、呼び名を付ける（地図が出なければ現在地）。決めるときに「いつから」効かせるかを選び（初めは今日。2026-10-08 に足した。2026-10-08-home-base-from.md）、その日から後の記録にだけ効き、履歴を残す（直す・消すもできる）。決めるまでは遠征も無い。秘伝「拠点を構える」は初めて決めたときに会得。拠点は端末とバックアップにだけ置き、共有カードにも入れない。場所の名前を調べる通信はしない。道中記の土地の一文と秘伝「遥かなる遠征」は、いつもの店からの距離で決める
- 理由: 家の位置は持たず、食べた店の集まりから推すより本人が決めるほうが確かなため（利用者の判断）。引っ越し前の遠征が変わらないように
