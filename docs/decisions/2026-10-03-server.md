# 店の検索は麺印帳のサーバー（Cloudflare Pages）経由

- 日付: 2026-10-03
- 決定: `site/`（Cloudflare Pages。紹介ページと Pages Functions の API `/api/v1/...`、https://ramen-in-cho.aiandrox.com）で、手で持つ店・Overpass・OpenPOI・Yahoo! をまとめて返す。結果は Cache API に1週間（失敗を含むときは1日）ため、誰が探したかは残さない。アプリはサーバーに6秒まで待ち、届かなければ端末から直接 Overpass・OpenPOI・手で持つ店で探す
- 理由: 検索の決まりと手で持つ店をアプリの更新なしで直せるようにし、先の検索サービスへの問い合わせを減らすため（aiandrox の判断）。サーバーが落ちても検索できるように
