# 使い方は、設定から開く画面の絵を1枚ずつめくって見せる

- 日付: 2026-10-08
- 決定: 設定に「使い方」を置き、項目（記録する・いま並んでいる・撤退・★をあとで付ける・願掛け・地図で店を探す・旅路・拠点・修行タブ・共有・バックアップ）を選ぶと、実際の画面の絵を1枚ずつ横にめくって見せる。1枚に1つのことを1〜2文で添える。ほかの画面に「？」は置かない。点の決まり方・印の字や形の意味・まだ会得していない秘伝の中身は書かない。絵は `test/tool/help_shots_test.dart` が架空の店名・地名・座標で実際の画面を描き、`cwebp` で幅480の WebP（品質70）にして `assets/help/` に同梱する（18枚で約400KB）。画面を変えたら `--dart-define=UPDATE_HELP_SHOTS=true` で作り直す。ふだんのテストでは、どの絵の画面も描けることと、絵のファイルがそろっていることを確かめる。地図の絵は地図の画像（タイル）を取りに行けないので、地図の画像の無い地にピンと線だけが出る。記録の写真は丼の絵で代える（一覧の写真は丼のアイコンのまま）
- 「使い方をもう一度見る」（はじめの案内）との関係: 設定の入口は「使い方」1つにまとめ、使い方の画面のいちばん下に「はじめの案内をもう一度見る」を置く。はじめの案内は拠点の決め方と始め方を選ぶ流れなので、使い方の説明とは役割が違い、並べると同じものが2つあるように見えるため
- 理由: 文章だけを並べた説明は読まれないため、画面の絵を1枚ずつ見せる（利用者の判断）。入口は設定だけ（利用者の判断）。点の決まり方などを書かないのは、遊びながら見つける楽しみを残すため（#309）
