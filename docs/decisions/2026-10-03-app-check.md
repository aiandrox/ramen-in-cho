# サーバーの API は Firebase App Check と回数制限で守る

- 日付: 2026-10-03
- 決定: アプリは `X-Firebase-AppCheck` を添え、サーバー（`site/functions/api/_middleware.ts`）は確かめて断る（`APP_CHECK_ENFORCE = "true"`）。家族の Android 用に開発用の鍵とアップロード鍵の SHA-256 も登録した。1台あたり1分60回・1日600回まで（App Check のアプリ ID ＋ IP、鍵は SHA-256 にして IP を残さない）。断られてもアプリは端末から直接探す
- 理由: API を誰でも呼べると Yahoo! の上限や無料枠を使い切られるため（aiandrox の判断で Firebase を許可）
- 関連: #131, #192
