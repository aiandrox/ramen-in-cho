# Yahoo! の検索結果はサーバーでためず、1日の回数を数える

- 日付: 2026-10-08
- 決定: サーバーは Overpass・OpenPOI の結果だけを Cache API に1週間（失敗を含むときは1日）ため、Yahoo! ローカルサーチとジオコーダの結果はためずに毎回問い合わせて混ぜる（同じ店は OSM → Yahoo! → OpenPOI の順に残す決まりは変えない）。Yahoo! への問い合わせ（ローカルサーチとジオコーダを合わせて）は D1 の `yahoo_daily_usage` に日本時間の1日1行で数え、4万5千回を越えた日は Yahoo! を使わずに探す。残すのは日付と回数だけ。数えられないときも Yahoo! を使わない
- 理由: YOLP の利用条件に「Yahoo! が別途認めた場合を除き、提供される情報を保存（キャッシュを含む）してはならない」とあるため。ためないと Yahoo! への問い合わせが増えるので、1日5万回の上限を越えないよう見張る。Yahoo! への問い合わせはしない（2026-10-09 利用者の判断）。ためない作りのまま続け、利用者が選んだ店を記録として端末に残すことは、利用者自身の記録として扱う
