# 決定事項

「なぜ今こうなっているのか」を残す置き場所。今の決まりそのものは [CLAUDE.md](../../CLAUDE.md) に書き、ここには理由と経緯だけを置く。

## 書き方

- 1件1ファイル。名前は `YYYY-MM-DD-<英語の短い名前>.md`（例: `2026-10-06-notifications.md`）。日付順に並ぶので、この README には一覧を書かない（並列の作業で衝突しないように）
- 中身は次の形にする

  ```markdown
  # 決まったことを1行で

  - 日付: 2026-10-06
  - 決定: 何をどうするか
  - 理由: なぜそうしたか（誰の判断か）
  - 関連: #123（issue・PR。無ければ書かない）
  ```

- 今の決まり（作り方・通信先・データ・計算式・画面の流れなど）が変わるなら、`CLAUDE.md` の本文も同じ PR で直す
- 前の決定を覆したときは、前のファイルを消すか書き直し、今の決まりだけが残るようにする（経緯は git の履歴と PR に残る）
- 小さな見た目の調整など、理由を読み返す必要の無いものは書かなくてよい（PR の説明で足りる）
