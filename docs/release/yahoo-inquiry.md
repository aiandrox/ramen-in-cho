## 本文

件名: 無料のラーメン記録アプリでの YOLP の結果のキャッシュと保存について

> Yahoo!デベロッパーネットワーク YOLP ご担当者様
>
> ［名前］と申します。個人で「麺印帳」（めんいんちょう）というラーメンの記録アプリ（iOS・Android）を開発しており、YOLP のローカルサーチ API とジオコーダ API を利用しています。利用条件について3点確認させてください。
>
> ■ アプリの概要
> - 食べたラーメンを写真とともに端末内に記録する、個人開発のアプリです。紹介ページ: https://ramen-in-cho.aiandrox.com
> - 無料で提供し、広告・アプリ内課金・有料プランはありません。ログインも無く、記録や写真は利用者の端末にだけ保存し、当方のサーバーには送りません。
> - 現在は開発者と家族で使っており、今後 App Store・Google Play で一般に公開する予定です。
>
> ■ YOLP の使い方
> - ローカルサーチ API: 記録するときに、現在地の周辺（半径300m程度）のラーメン店（業種コード 0106）や、入力した店名に合う店を探し、候補として表示します。
> - ジオコーダ API: ほかのアプリから共有された店の住所を、位置（緯度経度）にするときに使います。
> - どちらも当方のサーバー（Cloudflare 上、ramen-in-cho.aiandrox.com）からだけ呼び出し、アプリケーションID はサーバーにだけ置いています。OpenStreetMap など他の情報源の結果とまとめて、アプリに返しています。
> - クレジット「Web Services by Yahoo! JAPAN」は、検索結果の画面・地図・出典の画面と紹介ページに、https://developer.yahoo.co.jp/sitemap/ へのリンクで表示しています。
> - 1日の呼び出し回数は、現在［100回］程度です。一般に公開した後も、当面は数千回程度と見込んでいます。上限（1日5万回）に近づいたら、その日は YOLP を使わないようにサーバーで回数を数えています。
>
> ■ 確認したいこと
> 1. **サーバーでのキャッシュ**: 同じ場所・同じ店名の検索に、ローカルサーチ・ジオコーダの結果を当方のサーバーで一定期間（例えば1週間）キャッシュして返してもよいでしょうか。利用条件の「当社が別途認めた場合」に当たるかを伺いたいです。現在はキャッシュせず毎回呼び出していますが、店の情報はそう頻繁には変わらないため、キャッシュできれば御社への同じ問い合わせを減らせます。キャッシュは検索の条件（場所のおおよその区画や店名）ごとで、誰が検索したかは記録しません。
> 2. **利用者の記録への保存**: 利用者が検索結果から「自分が食べた店」「行きたい店」を選んだとき、その店の名前と位置（緯度経度）、住所から求めた位置を、利用者の端末の中の記録（とその記録を利用者が書き出すバックアップ）として残しています。これは「ユーザーに対して意図して保存させる」ことに当たるでしょうか。当たる場合、どのような形なら認めていただけるでしょうか。
> 3. **非商用に当たるか**: 上記のとおり、無料・広告なし・課金なしで個人が一般に公開するアプリは、利用規約の「非商用目的」の利用、および YOLP の無料での利用の範囲に当たると考えてよいでしょうか。
>

>
